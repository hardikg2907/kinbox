Status: open

## Question

On a phone, how does type -> pick -> save look and behave?

- What each search result shows (poster, year, Movie or Series, maybe top cast) and how Movies and Series are told apart.
- What is set at save: default status, optional recommended by, optional note; the "add as watched" path.
- What happens when the Title is already in the Library.
- From [Statuses and watches](02-statuses-and-watches.md): adding straight as watched is one tap, dated "date unknown" without asking; pick plain words for each Status and for "Watched again".
- What the person sees when TMDB has no match.
- Framework-free prototype that calls TMDB live, with the key from the TMDB key ticket.
- From [Series progress](05-series-progress.md): choosing Watching while adding a Series offers an optional "Where are you?" (Season and Episode), never required. Picking a place marks the earlier Episodes watched.
